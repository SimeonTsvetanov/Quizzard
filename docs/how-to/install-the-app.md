# Install the app

This guide shows you how to install Quizzard so it opens like an app, how to open a tool directly from its icon, and how Quizzard behaves without internet.

## Install on Android or a computer, in Chrome or Edge

1. Open [Quizzard](https://simeontsvetanov.github.io/Quizzard/) in Chrome or Edge.
2. Go to **Menu** > **Install app**.
3. Confirm the install in your browser's prompt.

If your browser doesn't offer the install, **Install app** opens a window with the steps for your browser: use its menu or the install icon in the address bar, and choose "Install". When Quizzard is installed, the menu item reads **Installed ✓**.

If your browser offers the install, Quizzard can also show a note with an **Install** button when you are back on the home screen after a tool saved something. It never shows the note on top of a tool, and at most once in 30 days.

## Install on iPhone or iPad

1. Open Quizzard in Safari.
2. Select **Share**, the square with an arrow.
3. Select **Add to Home Screen**.
4. Keep **Open as Web App** turned on.
5. Select **Add**.

Quizzard appears on your Home Screen and opens in its own window. A site you only open in a Safari tab can lose its saved data after a week without a visit, so install Quizzard or export your data. See [Back up and move your data](back-up-and-move-your-data.md).

## Open a tool from the icon

Long-press the icon of the installed app. Where your device supports app shortcuts, a list shows **Teams**, **Scores**, **Answer sheet** and **Quiz creator**. Select one to open that tool directly. Not every device shows shortcuts.

## Use Quizzard offline

Open Quizzard once while you are online. It shows **Ready to work offline ✓** when the offline copy is complete. After that, all four tools work without internet, whether you installed Quizzard or not. Your names, players, scores, answers and quizzes are saved on the device either way.

When you are offline, a small **Offline — still works** label appears in the header. Sharing to another app needs that app's own connection, and opening GitHub from **Report a problem** needs internet.

## Update Quizzard

When an update is ready, Quizzard shows a note with a **Reload** button. Select **Reload** when it suits you. Quizzard never reloads by itself, and your data stays saved.

To look for an update yourself, go to **Menu** > **Check for updates**. If there is a newer version, Quizzard loads it and reloads. If not, it says **You have the latest version** with the version number. Checking needs internet.
